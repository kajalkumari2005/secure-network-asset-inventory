# Linux Commands Documentation

## 1. pwd
Shows the current working directory.

## 2. ls
Lists files and folders in the current directory.

## 3. cd
Changes the current directory.

## 4. mkdir
Creates a new directory.

## 5. touch
Creates a new empty file.

## 6. nano
Creates or edits a text file.

## 7. cat
Displays the contents of a file.

## 8. cp
Copies files or directories.

## 9. mv
Moves or renames files and directories.

## 10. rm
Removes files.

## 11. rmdir
Removes an empty directory.

## 12. clear
Clears the terminal screen.

## 13. whoami
Displays the current logged-in username.

## 14. hostname
Displays the system hostname.

## 15. uname
Displays system and operating system information.

## 16. ip
Displays or manages network information.

## 17. ping
Tests network connectivity to another host.

## 18. sudo
Runs a command with administrative privileges.

## 19. apt
Manages software packages in Kali Linux.

## 20. man
Displays the manual/help page for a command.
