# Secure Network Asset Inventory & System Information Scanner

## Project Overview
This project is a Python-based system information scanner developed as part of the Cyber Security & Ethical Hacking Internship.

The application collects basic host and network information and saves the results into a text report.

## Objectives
- Identify host information
- Retrieve network details
- Display operating system information
- Generate a structured inventory report
- Save the results to a text file

## Features
- Hostname detection
- Local IP address detection
- MAC address retrieval
- Operating system information
- Network interface listing
- Report generation

## Technologies Used
- Kali Linux
- Python
- Git
- GitHub
- Bash Terminal

## Output
The scanner generates a `system_report.txt` file containing:
- Hostname
- Local IP address
- MAC address
- Operating system information
- Network interfaces

## Project Files
- `scanner.py` — Python source code
- `system_report.txt` — Generated system information report
- `task1.txt` — Task documentation
